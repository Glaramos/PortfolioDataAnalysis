Preparación y Análisis de Datos – Yerba Mate

Proyecto de limpieza, transformación y análisis exploratorio de datos relacionados con la producción de yerba mate durante el período 2022–2024.

1. Limpieza y Preparación de Datos

El objetivo de este proyecto es mejorar la calidad y consistencia del conjunto de datos para facilitar su análisis posterior. Durante la exploración inicial se revisaron distintos problemas de calidad que podían afectar la interpretación de los resultados.

Principales tareas realizadas

  • Identificación y revisión de registros duplicados.
  • Detección y tratamiento de valores faltantes.
  • Corrección de inconsistencias en nombres y categorías.
  • Estandarización de etiquetas y formatos de texto.
  • Revisión de valores numéricos fuera de los rangos esperados.
  • Validación de tipos de datos y consistencia de las variables.
  • Exportación del conjunto de datos preparado en formato CSV.

También se revisaron variables como kilos cosechados, hectáreas cultivadas, costos operativos, precipitaciones y rendimiento por hectárea, con el objetivo de mejorar la calidad de la información.

Resultado: un conjunto de datos más organizado y consistente, preparado para el análisis exploratorio y la elaboración de visualizaciones.

Tecnologías: Python, Pandas, NumPy y Jupyter Notebook.

GitHub Kaggle

2. Análisis Exploratorio de Datos (EDA)

Una vez preparados los datos, se realizó un análisis exploratorio para estudiar las variables, identificar patrones y comprender mejor el comportamiento de la producción de yerba mate.

Preguntas de análisis

  • ¿Qué zonas presentan mayor rendimiento por hectárea?
  • ¿Qué diferencias se observan entre cultivos orgánicos y convencionales?
  • ¿Qué relación existe entre las precipitaciones y la producción?
  • ¿Qué fincas presentan menores costos por kilogramo producido?

Para explorar estas preguntas se utilizaron estadísticas descriptivas, comparaciones entre categorías y visualizaciones que facilitan la interpretación de los resultados.

Resultado: una exploración de los datos orientada a identificar tendencias, relaciones entre variables y aspectos relevantes para el análisis de la producción.

Tecnologías: Python, Pandas, NumPy, Matplotlib, Seaborn y Jupyter Notebook.

Preparación y Análisis de Datos – Ventas de Supermercado

Proyecto orientado a mejorar la calidad de los datos de ventas y explorar información comercial mediante herramientas de análisis de datos con Python.

1. Limpieza y Preparación de Datos

Este proyecto se centra en la limpieza y estandarización de un conjunto de datos de ventas de supermercado. El proceso busca reducir inconsistencias y preparar la información para realizar análisis comerciales.

Principales tareas realizadas

  • Exploración de la estructura y los tipos de datos.
  • Identificación y revisión de registros duplicados.
  • Detección y tratamiento de valores faltantes.
  • Normalización de categorías y nombres de productos.
  • Revisión y estandarización de los métodos de pago.
  • Verificación de importes, cantidades y variables relevantes.
  • Preparación del conjunto de datos para el análisis posterior.

Resultado: datos revisados y preparados para estudiar el comportamiento de las ventas, los productos y las principales variables comerciales.

Tecnologías: Python, Pandas, NumPy y Jupyter Notebook.

GitHub Kaggle

2. Análisis Exploratorio de Ventas (EDA)

En esta etapa se exploran las transacciones de ventas para identificar patrones de consumo, comparar categorías de productos y estudiar el comportamiento de distintas variables comerciales.

Aspectos analizados

  • Distribución de las ventas según la categoría de producto.
  • Productos con mayor cantidad vendida.
  • Ingresos según el método de pago.
  • Evolución de las ventas a lo largo del tiempo.
  • Comparación de importes y precios medios de venta.

Visualizaciones

  • Gráficos de barras para comparar categorías y productos.
  • Gráficos de ingresos por método de pago.
  • Gráficos de líneas para examinar la evolución temporal.
  • Comparaciones de indicadores comerciales.

Las visualizaciones permiten interpretar los resultados, reconocer patrones y detectar aspectos que pueden ser útiles para profundizar en el análisis comercial.

Tecnologías: Python, Pandas, NumPy, Matplotlib, Seaborn y Jupyter Notebook.
